# Internship Hub

Buat platform LMS magang dengan integrasi Supabase Auth. Sediakan 3 role: Admin, SMK, dan Mahasiswa. Jika user role = SMK, tampilkan antarmuka untuk nonton video YouTube (dari tabel modules) dan kerjakan kuis (dari tabel quizzes). Jika role = Mahasiswa, tampilkan form submit link weekly report (ke tabel weekly_reports). Jika role = Admin, tampilkan dashboard kelola materi dan pantau laporan.
